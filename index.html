How to Read This Dashboard Hover any metric header for the exact green/yellow/red cutoffs.
1. Start With Tier Prioritize means the design passes the hard failure gates and has strong support across AF3, Rosetta, Boltz screen, and pose agreement. Back-up designs are still plausible but have weaker or more mixed evidence. Deprioritize designs either fail a hard gate or do not satisfy the Tier 1 / Tier 2 rules.
2. Then Use Rank Rows are ordered by final rank within the tier system. The final score is weighted toward independent validation: AF3 45%, Rosetta 30%, Boltz screen 15%, and pose agreement 10%.
3. Read Colors Green metric cells indicate strong evidence, yellow cells indicate acceptable but weaker evidence, and red cells flag concerns. A single yellow metric is usually not decisive; repeated yellow/red signals across AF3 or Rosetta are more important. Hover any metric header for exact thresholds.
4. Interpret Blocks AF3 asks whether an independent structure predictor supports the complex. Rosetta checks interface physics after relaxation. Boltz screen preserves the original campaign signal. Pose agreement checks whether AF3 keeps a similar binder pose to the Boltz-generated model.
Fatal Gates These override the weighted score. A design is deprioritized if AF3 iPSAE < 0.60, AF3 iPTM < 0.50, AF3 min iPAE > 12, binder RMSD > 3.5, Rosetta SC < 0.50, dG/dSASA > -1.5, or unsatisfied H-bonds > 6.
